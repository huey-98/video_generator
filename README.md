# AI 视频生成器

基于**阿里百炼平台 · 通义万相视频模型**的 Web 视频生成工具，Python 3.12 + Gradio。

## 功能

- 🎛️ **4 个模型自由切换**（切换后界面参数自动适配）：

  | 模型 ID | 说明 | 时长 | 分辨率 | 参考图 | 参考视频 |
  |---|---|---|---|---|---|
  | `wan2.7-t2v-2026-06-12` | 文生视频 | 2~15 秒 | 720P / 1080P | 不支持 | 不支持 |
  | `wan2.7-r2v-2026-06-12` | 参考生视频（锁定主体外观/动作） | 2~15 秒 | 720P / 1080P | **至少 1 个**，≤5 | 同上，**与图合计 ≤5** |
  | `wan3.0-video` | 新一代全能模型，原生音画同步 | 2~30 秒 | 480P / 720P / 1080P | 可选，≤10，**仅限 URL** | 可选，≤5，**仅限 URL** |
  | `wan3.0-video-prime` | 万相3.0 高速版 | 2~30 秒 | 480P / 720P / 1080P | 可选，≤10，**仅限 URL** | 可选，≤5，**仅限 URL** |

## 参考素材（参考图 / 参考视频）使用说明

平台的参考素材字段结构为（2026-09-24 直接探测平台校验报错确认）：

```json
{
  "input": {
    "prompt": "提示词",
    "media": [
      {"type": "reference_image", "url": "https://... 或 data:image/png;base64,..."},
      {"type": "reference_video", "url": "https://... 或 data:video/mp4;base64,..."}
    ]
  }
}
```

**实测规则：**

| 规则 | `wan2.7-r2v` | `wan3.0-video` / `-prime` |
|---|---|---|
| `type` 合法取值 | `reference_image` / `reference_video` / `first_frame` | 同左 |
| 参考图上限 | 5 | 10 |
| 参考视频上限 | 5 | 5 |
| **合计上限** | **media 数组最多 5 项（图 + 视频合计）** | 两类分别计数，故合计可达 15 |
| 能否混用图 + 视频 | ✅ 可以 | ✅ 可以 |
| 本地上传 | ✅ 图、视频均可（内联为 base64，平台再转存 OSS） | ⚠️ 不收 base64，但可**上传换 `oss://` 临时URL**（见下节） |
| 素材是否必传 | 至少 1 个（只给参考视频也可以） | 可选 |

- 报错 `Media array is too long, a maximum of 5 items are required` = 超出上表的合计上限
- `first_frame`（首帧）不能单独出现（平台报 `Only first frame provided is not allowed`），本工具暂未在界面开放该类型

## 本地文件怎么变成 URL（万相3.0 系列必需）

万相3.0 系列不收 base64，但**不需要自己找图床**——百炼提供免费的临时存储空间。
界面里选好本地文件 → 点「📤 上传换取临时URL」→ 程序自动上传并把 `oss://` 地址填进 URL 框。
（生成时若还有没上传的本地文件，提交前会自动补传，不会漏。）

接口流程（2026-09-26 实测跑通，实现见 `src/client.py` 的 `upload_file`）：

1. `GET {base_url}/uploads?action=getPolicy&model={模型ID}` → 拿到 OSS 上传凭证
2. `POST {upload_host}`（multipart 表单，字段：`key` / `policy` / `OSSAccessKeyId` / `signature` / `file`）
3. 得到可直接填进 `input.media[].url` 的 `oss://{upload_dir}/{文件名}`

**三条平台规则**（[官方文档](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)）：

| 规则 | 说明 |
|---|---|
| 有效期 | 上传后 **48 小时**失效，需在有效期内完成生成 |
| 模型绑定 | 上传时指定的模型必须与后续调用模型**一致**，不能跨模型共用 |
| 账号绑定 | 上传与调用必须是同一主账号的 API Key |

- 上传接口**免费**，单文件上限 1GB（模型另有更严限制：参考图 ≤20MB、参考视频 ≤100MB）
- ⚠️ **关键**：调用接口时请求头必须带 `X-DashScope-OssResourceResolve: enable`，
  否则平台不会去解析 `oss://` 地址。程序已自动判断并添加（见 `client.py` 的 `has_oss_url`）
- 文件上传后不可查询/修改/下载，仅能通过 URL 参数在模型调用时使用

## 提示词怎么写（含素材编号）

**核心规则：提示词里用「图1」「图2」「视频1」「视频2」指代参考素材，编号 = 素材添加顺序。
图片和视频各自从 1 开始计数，序号互不占用。**

```
图1   = 第 1 张参考图      图2   = 第 2 张参考图      （以此类推）
视频1 = 第 1 个参考视频    视频2 = 第 2 个参考视频    （以此类推）
```

界面上传素材后，下方会实时显示**素材编号对照表**（如 `图1 = 角色.png`、`视频1 = 舞蹈.mp4`），
照抄编号写提示词即可，不用自己数。

**依据**：阿里云开发者官方文章《万相3.0视频生成模型介绍》原文——

> 在提示词中可使用"图1""视频1""音频1"等指代 `input.media` 数组中对应顺序的素材，
> 且**图片、视频、音频分别计数，互不冲突**。

该文同时给出的上限（与直接探测平台校验报错的结果一致）：参考图 ≤10 张、参考视频 ≤5 段
（总时长 ≤15 秒）、多模态素材总共 ≤20 个。wan2.7-r2v 的编号规则未见单独说明，
按同一约定实现（其 media 总数上限为 5，为实测值）。

**示例：**

| 场景 | 提示词 |
|---|---|
| 锁人物外观 + 换服装 | `图1中的女孩穿上图2里的红色外套，在城市街头向前走，镜头缓慢推近，电影级画质` |
| 复刻动作/运镜 | `图1中的人物复刻视频1里的舞蹈动作，固定机位，明亮日光，浅景深` |
| 多主体同框 | `图1的男孩和图2的女孩并排坐在长椅上聊天，镜头缓慢横移，傍晚暖光` |
| 纯文生视频 | `一只小猫在月光下的屋顶上奔跑，城市霓虹灯在远处闪烁，电影级画质` |

**写好的通用建议**（适用于所有模型，属于经验性建议而非平台硬性规范）：

- 按「**主体 + 场景 + 运动 + 运镜 + 光影/风格**」的顺序写，比堆砌形容词有效
- 运动要写具体：`镜头缓慢推近`、`从左向右横移`，比只写"很酷"好得多
- 需要多镜头时按「第1个镜头[0-3秒]…；第2个镜头[4-6秒]硬切转场，固定机位…」的格式分段
- 有「智能改写提示词」（prompt_extend）时不必过度雕琢措辞，它会把短句扩写完整；
  想要精确控制镜头时再关掉它
- 参考素材锁的是「像不像」（主体外观 / 动作），画面最终效果仍要靠提示词描述

- 👀 上传的参考图 / 参考视频**即时预览**：上传区直接显示缩略图，编号（图1、视频1…）
  就标在缩略图上，与写提示词该用的编号一致；**点缩略图**会在**右下角悬浮窗**显示原图
  或播放原视频，超出窗口自动等比缩小、完整不裁切，确认无误再生成
- ⏳ 生成过程实时显示任务状态与用时（异步任务：提交 → 轮询 → 下载）
- 🖼️ 参考图 / 参考视频均支持**本地上传**或**粘贴 URL**（每行一个，可与本地文件混用）：
  万相2.7 把本地文件直接内联为 base64；**万相3.0 系列点一下「📤 上传换取临时URL」即可**
  （用百炼免费的临时空间，不用自己找图床，详见下节）
- 💰 费用预估（在 `config.yaml` 中填写模型单价后启用）
- 🔍 任务续查：任务一创建就记录 task_id，超时/关页面/中断后可在面板里查询，
  已完成的任务能直接下载回本地——**不必重新生成，不会重复计费**
- 📁 历史记录：每次生成的视频 + 参数元数据保存在 `outputs/`，点击即可回看
- 🌱 高级参数：负面提示词、随机种子、智能改写、水印

## 快速开始

```bash
# 1. 安装依赖（已在 .venv 中完成）
.venv/Scripts/python.exe -m pip install -r requirements.txt

# 2. 配置 API Key：打开 .env，填入百炼 API Key
#    DASHSCOPE_API_KEY=sk-xxxx

# 3. 启动
.venv/Scripts/python.exe main.py
```

浏览器自动打开 http://127.0.0.1:7860 （`--no-browser` 可禁止自动打开，`--port 7861` 可换端口）。

## 目录结构

```
video_genetor/
├── main.py            # 启动入口
├── config.yaml        # 模型注册表 + 默认参数（改配置即可调模型，无需动代码）
├── .env               # API Key（不要提交到 git）
├── src/
│   ├── config.py      # 配置加载
│   ├── registry.py    # 模型能力描述（含参考素材规格）
│   ├── payload.py     # 按模型能力组装请求体（media 数组）
│   └── client.py      # 百炼 API 客户端（原生 HTTP 异步任务 + 上传文件换临时URL）
├── ui/webui.py        # Gradio 界面
└── outputs/           # 生成的视频（.mp4）+ 参数元数据（.json）
```

## 生成耗时参考（实测）

| 场景 | 实测耗时 |
|---|---|
| `wan2.7-t2v` 10 秒 720P | 约 5~6 分钟 |
| `wan2.7-r2v` 5 秒 720P + 1 张参考图 | **约 29 分钟** |
| `wan3.0-video` 2 秒 480P + 1 张 `oss://` 参考图 | 约 1.6 分钟 |

参考生视频（r2v）明显更慢，请预留足够时间。**超时 ≠ 失败**：任务往往仍在平台执行，
超时后 task_id 会自动填入界面底部的「任务续查」，过一会儿点「查询状态」即可把已生成好的
视频直接取回本地（不会重复计费）。

## 常见问题

1. **创建任务失败 / 提示地域相关错误**：API Key、模型、域名必须同属一个地域。
   北京地域默认 `https://dashscope.aliyuncs.com/api/v1`；若你的业务空间使用专属域名，
   在 `.env` 中设置 `DASHSCOPE_BASE_URL=https://{业务空间ID}.cn-beijing.maas.aliyuncs.com/api/v1`。
2. **生成耗时**：视频生成是异步任务，通常 1~5 分钟，界面会实时显示状态，请耐心等待。
3. **视频链接时效**：平台返回的视频 URL 仅 24 小时有效，程序已自动下载到 `outputs/`。
4. **参考素材相关**：
   - 本地上传单个参考图不超过 8MB、单个参考视频不超过 30MB（**base64 路径**的保护性上限，
     因为 base64 会放大 1/3 体积）。走「上传换取临时URL」时按平台上限：图 ≤20MB、视频 ≤100MB
   - 参考图**至少 240×240 像素**（平台硬性要求；界面已做提交前预检，不合规会直接拦下）
   - 提示 `only accept http/https`：该模型（wan3.0 系列）不收 base64，改用
     「📤 上传换取临时URL」即可，不必自己找图床（见上文《本地文件怎么变成 URL》）
   - 提示 `Media array is too long` = 参考图 + 参考视频合计超过上限（r2v 为 5 个）
   - 参考视频本身的分辨率/时长限制未在本机实测（需要真实视频素材），若平台返回
     相关 `InvalidParameter`，把完整报错发我，或直接在 `config.yaml` 里调整 `refs` 段
   - 提示 `Field required: input.media` 之类的参数错误，说明平台字段结构又变了——
     把完整报错发给我，或在 `config.yaml` 中调整对应模型的 `refs` 配置（字段名/结构都在那里，无需改代码）
5. **费用**：按生成秒数计费，任务**提交即扣费**（失败通常返还，以平台规则为准）。
   测试时建议用「最短时长 + 最低分辨率」。价格见
   [百炼计费页](https://help.aliyun.cn/zh/model-studio/billing)，
   查到单价后可填入 `config.yaml` 中对应模型的 `price_per_second` 以启用费用预估。
6. **模型参数更新**：若百炼调整了某模型的参数（如参考图字段名、分辨率档位），
   直接修改 `config.yaml` 中对应模型的配置即可，无需改代码。

7. **控制台出现 `ConnectionResetError` / `Exception in callback
   _ProactorBasePipeTransport._call_connection_lost`**：这是 Windows 上 asyncio 的已知噪音
   （浏览器关闭/刷新连接时触发，[cpython#109383](https://github.com/python/cpython/issues/109383)），
   不影响生成。`main.py` 已做屏蔽处理。
